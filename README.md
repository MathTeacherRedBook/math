# 迈斯老师 · 初高中数学知识点（网页版）

把你整理的三套数学知识点（人教A版高中、人教版初中、北师大版初中）做成了一个可以直接打开、也可以部署上线的静态网站。

- 无需安装、无需数据库、无需后台：**双击 `index.html` 就能看**
- 手机、平板、电脑自适应
- 公式用 KaTeX 排版，字体、公式库都已放在本地，断网也能正常显示
- 目录、搜索、收藏、学习进度、深色模式、打印，都是纯前端实现

## 三、目录结构

```
mathsite/
├─ index.html                 # 页面骨架（一般不用改）
├─ assets/
│  ├─ css/site.css            # 全部样式（配色、字体、响应式）
│  ├─ js/app.js               # 路由、渲染、搜索、收藏、进度
│  ├─ js/data.js              # 站点数据（由 content/ 生成，不建议手改）
│  ├─ fonts/                  # 中文衬线字体子集（约 500KB）
│  └─ vendor/katex/           # 公式排版库（本地化）
├─ content/
│  ├─ content.py              # ★ 你的内容源：目录、导语、试读正文、联系方式
│  └─ formulas.py             # ★ 公式速查表
├─ tools/
│  ├─ build_data.py           # 把 content/ 编译成 assets/js/data.js
│  ├─ build_fonts.py          # 重新生成中文字体子集
│  └─ shoot.mjs / qa.mjs      # 我验收用的截图与检查脚本（可删）
└─ README.md
```

## 五、增加 / 修改知识点

### 数据结构

`content.py` 里每套资料的结构是：

```
BOOK（教材）
└─ volumes 册
   └─ chapters 章
      └─ sections 节（初中没有节，章本身就是最小单元）
         └─ points 知识点
```

一个知识点的写法：

```python
{
    "h": "基本不等式",              # 知识点标题，可以写 $...$ 公式
    "b": """若 $a>0,\\ b>0$，则

$$\\sqrt{ab} \\le \\frac{a+b}{2},$$

当且仅当 $a=b$ 时取等号。""",
}
```

`b` 是简化版 Markdown：

- `$...$` 行内公式，`$$...$$` 独占一行的公式
- `**加粗**`
- 以 `- ` 开头是列表，以 `1. ` 开头是编号列表
- 空行分段

章节还可以加：

- `"intro"`：本节导语
- `"tips"`：易错提醒（会渲染成红色提示块）
- `"story"`：小故事（会渲染成蓝色故事块，格式 `{"title": "...", "b": "..."}`）
- `"minutes"`：预计阅读分钟数
- `"free": True`：是否免费试读

改完运行 `python tools/build_data.py`。

### 想把某节也设为免费

在对应节里加一行 `"free": True`，重新生成即可。首页会多出「免费试读」入口，阅读页自动解锁。

## 六、部署上线

这是一个纯静态站点，**只需要上传 `index.html` 和 `assets/` 两个东西**（`content/`、`tools/` 不需要上传）。

常见选择：

1. **Vercel / Netlify**：把整个 `mathsite` 文件夹拖进去，自动分配域名，HTTPS 免费。
2. **GitHub Pages**：上传到仓库，Settings → Pages → 选择分支即可。
3. **阿里云 OSS / 腾讯云 COS**：开启静态网站托管，上传文件，绑定域名。
4. **自己的服务器 / 宝塔**：放到网站根目录即可。

> 如果要在**微信里直接打开并分享**，域名需要备案，并使用 HTTPS。

### 自定义域名后

记得把 `index.html` 里的 `<link rel="icon" ...>` 和页面 `<title>` 按需改一下（可选）。

## 七、关于字体与离线

- 公式（KaTeX）和中文字体都已本地化，不依赖任何 CDN，断网也能用。
- 中文标题用的是一款思源宋体子集，只包含站点里出现过的字（约 500KB）。
  如果以后新增了生僻字，那个字会回退到系统宋体，不影响阅读；
  想彻底一致，可以运行 `python tools/build_fonts.py` 重新裁剪
  （需要 `pip install fonttools brotli`，并把字体源文件放到 `tools/fonts-src/`）。
- 收藏和「已学」进度保存在浏览器 `localStorage`，换设备不会同步，也不会上传服务器。
